5. Condicionales

Una condicional deja que el programa tome caminos distintos según se cumpla o no una condición. El resultado de comparar dos valores siempre es un booleano (true o false), el tipo que se vio en el tema 3. Cuando hay varias condiciones encadenadas con if / else if, JavaScript las evalúa en orden y se detiene en la primera que sea verdadera; por eso conviene ir de lo más restrictivo a lo más general. Para comparar es importante usar === y no ==: el operador flexible hace conversiones de tipo antes de comparar, y eso produce sorpresas como que 0 == "" dé true. Cuando se necesita comparar una sola variable contra varios valores exactos, switch suele leerse mejor que una cadena larga de if; para rangos o condiciones compuestas, if sigue siendo la herramienta correcta.

Así se ve

// Varios caminos: se evalúa en orden y se detiene en el PRIMERO verdadero
if (nota >= 4.6) {
  nivel = "Superior";
} else if (nota >= 4.0) {
  nivel = "Alto";
} else if (nota >= 3.0) {
  nivel = "Básico";
} else {
  nivel = "Bajo";
}

Cuidado con

Escribir = donde debería ir === es un error muy fácil de cometer y muy difícil de notar: if (nota = 5) no compara nada, asigna el valor 5 a nota y esa asignación, al no ser cero ni vacía, siempre se evalúa como verdadera. El programa no lanza ningún error; simplemente entra siempre por la misma rama, sin avisar que algo está mal.

6. Ciclos

Un ciclo permite escribir una sola vez una instrucción que debe repetirse muchas veces, en vez de copiar y pegar diez líneas casi iguales. El for es el más usado cuando se sabe cuántas repeticiones se necesitan: tiene una inicialización, una condición y una actualización, en ese orden, ejecutadas en cada vuelta. El while se usa cuando no se sabe de antemano cuántas veces hay que repetir, solo la condición que debe cumplirse; y el do...while es igual, salvo que garantiza al menos una ejecución antes de revisar la condición. En muchos ciclos aparece un acumulador: una variable declarada fuera del ciclo que va sumando o construyendo el resultado en cada vuelta. Un descuido clásico es el ciclo infinito: si la condición nunca llega a ser falsa, la página se congela; antes de escribir un while conviene poder señalar exactamente qué línea hará que termine.

Así se ve

//      inicialización   condición   actualización
for (let i = 1;          i <= 10;    i++) {
  resultado += i + " ";
}
