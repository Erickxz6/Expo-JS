1. Qué es JavaScript

JavaScript es un lenguaje interpretado: no necesita compilarse antes de ejecutarse, el navegador lo lee y lo corre directamente. Es, además, el único lenguaje que los navegadores entienden de forma nativa; cualquier otro lenguaje que se use para la web termina convertido a JavaScript en algún punto. Dentro de una página cada tecnología cumple un papel distinto: el HTML pone el contenido, el CSS le da la apariencia y JavaScript se encarga del comportamiento, es decir, de todo lo que responde a una acción del usuario. Hoy en día JavaScript ya no vive solo dentro del navegador: con entornos como Node.js también corre en servidores, y se usa para construir aplicaciones de escritorio y aplicaciones móviles.

Cuidado con

Un error muy común de principiante es pensar que Java y JavaScript son el mismo lenguaje, o que JavaScript es una versión "ligera" de Java. No lo son: comparten parte del nombre por una decisión de mercadeo de los años 90 (Java estaba de moda y Netscape aprovechó el parecido), pero su sintaxis, su forma de ejecutarse y su propósito son distintos.

¿Por qué se parecen tanto los nombres si son lenguajes distintos?

JavaScript se llamó originalmente LiveScript. Netscape lo renombró a JavaScript como estrategia comercial, aprovechando la popularidad que Java tenía en ese momento, aunque el diseño interno de ambos lenguajes no tiene relación directa.
